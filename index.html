TelegramWin 1

TelegramWin 1 — бесплатное приложение для Windows, которое помогает незрячим пользователям удобнее работать с Telegram на компьютере.

Скачать TelegramWin 1

Системные требования

  • Windows 10 или Windows 11.
  • 64-битная система.

Функционал TelegramWin 1

  1. Открывает Telegram на компьютере.
  2. Показывает список чатов.
  3. Чаты можно закреплять.
  4. У чатов можно отключать звук уведомлений.
  5. Enter на чате открывает окно сообщений выбранного чата.
  6. В окне сообщений можно перемещаться по сообщениям стрелками.
  7. Enter на сообщении открывает сообщение в полном формате. Это особенно полезно для пользователей JAWS.
  8. Esc закрывает окно редактора и возвращает в окно сообщений.
  9. В окне сообщений можно открыть меню через контекстное меню или Shift+F10.
  10. Через меню можно написать сообщение, ответить на сообщение или удалить сообщение.

Это текущий функционал бесплатной версии TelegramWin 1.

Установка

  1. Распакуйте архив TelegramWin 1 в папку.
  2. Запустите файл TelegramWin1.exe.

Приложение не нужно устанавливать в систему. Оно запускается из папки.

Возможные проблемы при запуске

Если программа не запускается, возможно, на компьютере установлена старая версия Microsoft Visual C++ Redistributable.

Что сделать:

  1. Откройте папку TelegramWin 1.
  2. Запустите файл vc_redist.x64.exe.
  3. Дождитесь завершения установки.
  4. После установки снова запустите TelegramWin1.exe.

TelegramWin 2 — платная версия

TelegramWin 2 находится в разработке. Это будет расширенная платная версия с дополнительными возможностями.

Планируемые возможности:

  • просмотр реакций на посты и сообщения;
  • возможность ставить реакции;
  • чтение комментариев;
  • написание комментариев;
  • предупреждение JAWS о длинном посте;
  • быстрое открытие длинного поста через Enter для чтения целиком;
  • скачивание фото и видео;
  • переход по ссылкам из сообщений;
  • копирование текста сообщения;
  • добавление до трёх профилей в настройках;
  • переключение между профилями;
  • изменение звука входящих сообщений;
  • постепенное добавление новых возможностей.
